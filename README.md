# Bitácora Mobile

Distribución pública sanitizada de la PWA **Bitácora — Don Orlando López**.

- El código público contiene únicamente el shell y datos de demostración.
- Los datos que el usuario capture permanecen en el navegador del teléfono.
- Funciona offline después de la primera carga.
- Incluye IndexedDB, captura rápida, calendario `.ics` y respaldo/restauración JSON.
- No contiene secretos, credenciales, IDs productivos ni documentos privados.

Esta distribución se publica sin Vercel, Replit, Supabase ni gastos de hosting.
